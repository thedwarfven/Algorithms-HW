How the algorithm works

There are 2⁹ = 512 possible boards. Any coin starts a move, whether heads or tails. Its orthogonal neighbors flip with it. Every move is reversible. The reverse graph lets one BFS from the goal find shortest paths for every board.

for each state u:
  for each coin i:
    v = u XOR flipMask[i]
    reversedEdges[v].add((u, i))

distance[511] = 0
queue = [511]
while queue is not empty:
  v = queue.removeFirst()
  for (u, i) in reversedEdges[v]:
    if u is unvisited:
      distance[u] = distance[v] + 1
      next[u] = v
      move[u] = i
      queue.add(u)
